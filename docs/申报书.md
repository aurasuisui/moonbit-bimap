## 项目简介

MoonBit BiMap 提供**双向映射(双射)**:键与值一一对应,正向 `get_by_left` 与反向
`get_by_right` 均 O(1) 查找,填补 MoonBit 内置 `Map` 只能单向、且值可重复的空白。
本库额外提供 Rust `bimap`/Guava 均不具备的**保插入序**与**按位置索引访问**,并含
排序变体 `BiBTreeMap`。与同生态的 `aurasuisui/indexmap`(保序哈希表)解决的是
**正交问题**,正交互补、不重合。

## 本期(9 月)新增实质工作 —— `from_json` 反序列化

- **范围**:`BiMap` 与 `BiBTreeMap` 的 `from_json`/`from_json_with`
  (字符串键直用,非字符串键可自定 `parse_key`),配统一错误类型
  `BiMapDecodeError`(语法/类型错误 `Decode` 与双射冲突 `DuplicateRightValue`
  严格区分)。
- **关键语义**:双射冲突**严格报错**(错误载荷含右值与两个冲突左键),不静默
  C3 蒸发;重复键 last wins(跟随 core 语义);错误优先级"值解码先于冲突检测";
  与既有 `ToJson` 构成**无损往返**(Eq 集合语义,`from_json(m.to_json()) == m`)。
- **配套**:序列化往返测试(Tier 0–2:单元 / QuickCheck 往返 / 模型比对 /
  Unicode 与转义键 / 10k+ 压力 / golden-file 格式快照)、README/SPEC/CHANGELOG
  文档同步、可运行示例。
- **目标版本**:`v0.3.0`(9 月内交付并发布至 mooncakes.io)。
